# YogoDot

ATK YOGO 75 PRO 的点阵屏和背光,不用开 ATK HUB 也能玩。

它宣传的「1.54 寸像素屏」实际是 **6×6 = 36 颗全彩 LED**。官方驱动只能往里写一张静态图,多帧动画根本传不到设备。这个工具直接跟键盘的 HID 通道说话,把点阵屏和 84 颗按键背光都变成可以随便刷的画布 —— 逐像素全彩、动画、零 flash 磨损。

> 非官方项目,与 ATK / Anthropic 没有任何关系。协议是从官方网页版 HUB 的前端代码里读出来的。自用工具,风险自负。

## 能做什么

**纯键盘模式(默认)**

- 点阵屏图案库:几十张 6×6 像素画,点一下就上屏,关掉软件再开还在
- 主题:一套配色 + 一张点阵图,键盘背光和点阵屏一起换
- 动态主题:点阵屏和背光一起动的动画
- 番茄钟:点阵屏画进度环,到点了背光提醒
- 专注模式:全灭
- 省电:锁屏立刻熄屏、空闲 3 分钟熄屏、低电量自动撤掉背光、电量和充电状态显示
- 开机自启,托盘常驻,没有黑框

**Claude 模式(控制台里手动打开)**

给同时在用 [Claude Code](https://claude.com/claude-code) 的人:

- 顶部胶囊:鼠标中键唤出,显示官方额度(5 小时 / 本周 / 按模型的周额度)和各会话状态,10 套皮肤、4 种动画
- Vibe 模式:点阵屏上一只电子宠物,跟着 Claude 的状态睡觉 / 张望 / 蹦跳 / 耷拉
- 可选:把远端服务器上的 Claude Code 会话也接进来

## 安装

要求:Windows 10/11、Python 3.11+、键盘走 **2.4G 接收器或有线**(蓝牙模式下驱动认不出键盘,这是键盘固件的限制)。

```bash
pip install -r requirements.txt
```

然后双击 `yogo.pyw`。它会:

- 常驻托盘,左键点托盘图标开控制台,右键菜单里有「开机自启」开关
- 自动建开始菜单和桌面快捷方式

控制台是一个本地网页(`http://127.0.0.1:8787/yogo.html`),用本机的 Chrome(没有就用 Edge)以应用窗口方式打开。关掉窗口不会退出程序,键盘的灯效由后台进程维持。

## 省电

推流模式下 LED 一直亮着是耗电大头,所以:

- **锁屏(Win+L)4 秒内全灭**,解锁原样恢复
- 键鼠 **3 分钟**没动全灭
- 「熄灭键盘灯」是固件级关闭(背光模式 0),不是推一帧黑色
- 电量 ≤20% 自动撤掉背光,≤8% 连点阵也停,充电中不降级
- 静态内容推一帧就停,零流量;动画点阵最高 6fps、背光 2fps

点阵屏亮度滑杆建议 50 左右,LED 电流跟亮度基本线性。

## Claude 模式

控制台左栏「Claude 模式」按钮打开。打开后才会出现 Vibe 模式、胶囊设置和额度显示。

**本机的 Claude Code** —— 把这段合并进 `~/.claude/settings.json`,额度和会话状态就有了:

```json
"statusLine": { "type": "command", "command": "py -3 <本项目目录>/statusline.py" }
```

**远端服务器上的 Claude Code**(可选)—— 把 `remote/` 里的两个脚本放到服务器的 `~/.claude/hooks/`,把 `remote/settings-hooks.json` 里的 hooks 合并进服务器的 `~/.claude/settings.json`,然后在本机 `settings.json` 里填 `"ssh_host": "<你的 ssh 主机别名>"`。本机会用 `ssh <主机> tail -F` 把事件流拉回来,不需要反向隧道。hook 全部是 `async`、永远 `exit 0`,不参与任何权限决策。

**按模型的周额度**(比如 Fable)—— `/api/oauth/usage` 需要交互式登录的凭据。如果服务器上有一直在跑的 Claude 会话,`remote/yogo-quota.py` 装成 systemd user service 就能拿到;`claude setup-token` 给的长期 token 没有这个权限。

## 它是怎么工作的

- `kbd.py`:Windows HID API(`setupapi` / `hid.dll`,纯 ctypes),直接持有键盘的厂商通道。去重、限速、尾沿补发、电量、熄屏都在这一层,上层再出 bug 也刷不爆设备
- `server.py`:本地 HTTP 服务,控制台页面只是遥控器
- `hud.py` + `capsule.py`:胶囊是 PIL 渲染的分层窗口,不是浏览器
- `yogo.html`:控制台,主题 / 图案 / 动画 / 番茄钟引擎目前在这里

点阵屏走 `set_dotscreen_matrix`(cmd 59),背光走 `open_sync_led`(cmd 46)的 RAM 推流,都不写 flash。配置读-改-写只在换模式时发生一次,第一次读到的原厂配置会存成 `config.bak`。

命令表里有 `reset_device`(49)就夹在常用号段中间。**探协议时不要盲扫命令号。**

## 已知限制

- 只支持 Windows。HID 层是 Win32 API
- 只在 ATK YOGO 75 PRO 上测过。同厂其他带点阵屏的型号协议可能相同,但没验证
- 蓝牙模式下无法控制
- 灯效内容不存在键盘里,程序退出后键盘回到固件默认画面;下次启动自动补推
- 键盘的 LED 发光效率 红:绿:蓝 ≈ 1:4:14,低饱和的颜色在灯珠上会发白。主题色都按这个校过,自定义图案时最大通道拉满、最小通道压到 50 以下效果最好

## 排查

- `py -3 hidprobe.py`:列出所有 HID 接口,对厂商口做一次握手
- `py -3 wake.py`:守着等键盘应答,插线 / 开机 / 换档时用
- `py -3 batt.py`:电量和可读配置区的原始字节
- `http://127.0.0.1:8787/kb/status`:连接、电量、熄屏、锁屏状态
- `yogo.log`:所有进程的日志都在这

「键盘完全没反应、接收器在系统里一切正常、厂商口握手不回包」= 键盘不在链路上:没电、没开、或者不在 2.4G 档。插根线看能不能打字。
