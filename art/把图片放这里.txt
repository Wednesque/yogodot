把图片按皮肤的角色名或皮肤名命名放在这个目录，胶囊的背景水印就会用它，
优先于内置的像素图样。支持 png / webp / gif / jpg。

文件名对应表（用哪个都行）：
  pika.png      或  皮卡丘.png      -> 皮卡丘皮肤
  charizard.png 或  熔岩.png        -> 熔岩皮肤
  shark.png     或  深海.png        -> 深海皮肤
  eva.png       或  初号机.png      -> 初号机皮肤
  leaf.png      或  苔.png          -> 苔皮肤
  penguin.png   或  极夜.png        -> 极夜皮肤
  cat.png       或  樱.png          -> 樱皮肤
  octopus.png   或  曜石.png / 霜.png
  bolt.png      或  赛博.png        -> 赛博皮肤

有透明通道的直接用透明通道；没有的按亮度自动去白底。
小于 64px 的按像素画放大（保持锯齿感），大图平滑缩放。
透明度固定在 ~18%，压在文字后面，放什么都不会影响可读性。
换完图重启托盘程序（托盘右键 -> 重启）即可生效。
