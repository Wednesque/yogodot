长什么样

控制台是本机网页，主题、图案、动画、番茄钟都在这里调；键盘的灯效由后台进程维持，关掉窗口不受影响。

能做什么

默认是一个纯键盘灯效工具，跟 Claude 有关的部分要手动打开。

点阵屏
像素图案库

几十张 6×6 像素画，点一下就上屏。关掉软件再开还在。你自己的图放进 art/ 就行。

主题
背光 + 点阵一起换

一套主题 = 一套逐键配色 + 一张点阵图。颜色按这块键盘的 LED 发光效率校过，不会发白。

动画
动态主题

点阵屏和背光一起动。官方驱动的「多帧动画」其实传不到设备 —— 这里是真的动。

番茄钟
进度环 + 到点提醒

点阵屏画进度环，到点背光闪一下。专注模式一键全灭。

省电
锁屏 4 秒内熄屏

Win+L 立刻全灭，解锁原样恢复；键鼠 3 分钟没动也熄。低电量自动先撤背光。电量和充电状态随时可见。

底层
不依赖 ATK HUB

纯 Python + Windows HID API，不联网。点阵和背光都走 RAM 推流，零 flash 磨损；原厂配置第一次读到就备份。

安装

不用装 Python，不用命令行。键盘要用 2.4G 接收器或有线连接 —— 蓝牙模式下固件不开放控制通道。

  1. 下载

    YogoDot-windows.zip，约 15MB。

  2. 解压到任意目录

    设置和图案选择会存在 YogoDot.exe 旁边，所以别放在 C:\Program Files（放了也能跑，会自动改存到 %LOCALAPPDATA%）。

  3. 双击 YogoDot.exe

    它会进托盘。左键点托盘图标开控制台，右键菜单里有开机自启开关。

Windows 会拦一下。这个 exe 没买代码签名证书（一年好几千，开源小工具就算了）， 所以第一次运行 SmartScreen 会弹「已保护你的电脑」。点「更多信息」→「仍要运行」即可。 介意的话可以看 源码 自己用仓库里的 build.cmd 打包，产物一模一样。

想改代码就从源码跑：pip install -r requirements.txt 之后双击 yogo.pyw。

Claude 模式

给同时在用 Claude Code 的人。控制台里一个按钮打开，默认关着。

顶部胶囊

鼠标中键唤出：官方额度（5 小时 / 本周 / 按模型的周额度）、各会话的状态、番茄钟。灵动岛式的动画。

Vibe 模式

点阵屏上一只电子宠物，跟着 Claude 的状态睡觉、张望、蹦跳、耷拉。有事可选弹一下胶囊。

远端会话

服务器上跑的 Claude Code 也能接进来 —— hook 全部异步、永远 exit 0，不参与任何权限决策。

跟 Claude Code 的对接方式在 README 里。

常见问题

它和 ATK HUB 冲突吗？
不冲突，但别同时开。两个程序抢同一个 HID 通道会互相打断。用 YogoDot 的时候把 ATK HUB 退掉就行。
支持别的 ATK 键盘吗？
只在 YOGO 75 PRO 上测过。同厂其他带点阵屏的型号协议可能相同，但没验证 —— 欢迎试完开 issue。
会不会写坏键盘？
点阵和背光都走 RAM 推流，不写 flash。配置读-改-写只在换模式时发生一次，原厂配置第一次读到就存成 config.bak，能整块推回去。
程序退出后键盘会怎样？
回到固件默认画面（一个红色的 0）。灯效内容不存在键盘里，下次启动自动补推。
Mac / Linux？
目前只有 Windows，HID 层是 Win32 API。协议本身是通用的，欢迎移植。
为什么 Windows 说它不安全？
没买代码签名证书而已。第一次运行点「更多信息 → 仍要运行」。源码全公开，也可以自己用 build.cmd 打包。
要联网吗？
纯键盘模式完全不联网。只有打开 Claude 模式、并且你自己配了账号或服务器，才会去读额度。

English: YogoDot is a third-party controller for the ATK YOGO 75 PRO keyboard's 6×6 dot-matrix screen and per-key RGB backlight — an alternative to the official ATK HUB driver. Pure Python + Windows HID, no flash writes. Pixel art library, themes, animations, pomodoro, power saving (blank on lock / idle). Optional Claude mode shows Claude Code quota and session state. Windows only; 2.4G dongle or wired.

非官方项目，与 ATK / Anthropic 无关。协议来自官方网页版 HUB 的前端代码。自用工具，风险自负。
