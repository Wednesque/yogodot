24 套主题，背光和小屏一起换

每套主题是一张小屏图案 + 一套 84 键配色，成套切换。颜色专门按这把键盘的灯珠调过 —— 灯珠发的光跟屏幕不一样，直接用普通配色会发白。

左边：实时预览上面是小屏，下面是 84 颗键盘灯，跟键盘上一模一样。
右边：点一下就换皮卡丘、吃豆人、精灵球、柴犬、初音、EVA…
顶上：切模式主题、番茄钟、专注（全灭）、开机动画。

不只是换图

这些都是软件自动做的，打开放在后台就行。

番茄钟

小屏画一圈进度，走满一圈到点，背光闪一下提醒你休息。

锁屏自动熄灭

按 Win+L 锁屏，几秒内键盘灯和小屏全灭；解锁原样亮回来。离开 3 分钟不碰电脑也会自动熄。

会动的主题

小屏和背光一起动：火苗、极光、心跳……为了省电，动画刷新得比较慢。

电量看得见，快没电自动省

软件里直接显示电量和是否在充电。低于 20% 自动关背光，低于 8% 小屏也关，插上电自动恢复。

常见问题

会不会弄坏键盘？

不会。不刷固件、不改按键。画面是实时发给键盘的，不存进键盘里；只有切换背光模式时会改一次键盘设置，跟官方驱动一样。想回到出厂状态，用官方 ATK HUB 的「恢复出厂」就行。

蓝牙连接能用吗？

不能。键盘在蓝牙模式下不接受电脑控制灯光（键盘自己的限制）。要用 2.4G 接收器或数据线，打字、续航都不受影响。

要联网吗？

不用。默认完全离线。只有你手动打开给程序员用的「Claude 模式」，才会读取电脑上 Claude Code 的登录信息去查用量。

关掉软件会怎样？

键盘上会留着最后一个画面，直到键盘休眠；之后回到键盘自带的显示。再打开软件会自动补上。

跟 ATK HUB 冲突吗？

别同时开。两个软件抢着控制同一把键盘会互相打断，用哪个就退出另一个。

别的键盘 / Mac 能用吗？

目前只在 YOGO 75 PRO 上测过，只有 Windows 版。同厂别的带像素屏的型号可能也行，欢迎试完告诉我。

Claude 模式

如果你在用 Claude Code：在软件里打开「Claude 模式」，键盘就变成它的状态灯。不用的人看不到这部分，也不会联网。

  • 屏幕顶上一个胶囊：Claude 用量（5 小时 / 本周 / 按模型）、各会话在干嘛。鼠标中键唤出 —— 所以开了之后中键归它用。
  • 小屏上一只电子宠物，跟着 Claude 的状态睡觉、张望、蹦跳、耷拉。
  • 远端服务器上的会话也能接进来。配置方法见 GitHub 说明。
